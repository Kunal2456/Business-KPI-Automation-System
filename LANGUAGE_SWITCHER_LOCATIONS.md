## ❓ Troubleshooting

### Can't Find Globe Icon?
1. **Check these locations**:
   - Landing page: Top right
   - App desktop: Left sidebar bottom
   - App mobile: Top header or menu
2. **Look for**: 🌐 with flag badge
3. **Try**: Refreshing the page

### Globe Icon Not Changing Language?
1. **Clear browser cache**
2. **Check console** for errors (F12)
3. **Try**: localStorage.clear() in console
4. **Refresh** page after clearing

### Language Switched But Some Text Not Changing?
- Some components need to be updated
- Check if component uses `useTranslation` hook
- Example component: `Hero.tsx` (working)
