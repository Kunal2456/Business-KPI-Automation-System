# ShelfIQ - Smart Inventory Intelligence Platform

## 📋 Problem Statement

1. **Manual Inventory Tracking** - Store owners struggle with spreadsheets and manual stock management
2. **No Business Insights** - Lack of real-time KPIs and sales analytics
3. **GST Compliance** - Complex GST invoice generation and tax reporting
4. **Multi-Store Management** - Difficulty managing inventory across multiple locations
5. **Data Entry Burden** - Time-consuming manual data entry processes

## 🛠️ Tech Stack

- **Frontend:** React.js + TypeScript
- **Styling:** Tailwind CSS v4
- **Routing:** React Router (Data Mode)
- **Backend:** Supabase (Database + Auth)
- **Charts:** Recharts
- **Icons:** Lucide React
- **Animations:** Motion (Framer Motion)
- **Mobile:** Converting to Android (Java + Android Studio)

## 💻 Platform

- **Web Application** - React.js SaaS
- **Mobile App** - Android (Java) - In Development
- **Responsive Design** - Works on all screen sizes
- **Dark Mode** - Complete theme support

## 🎯 Core Features

### Inventory Management
- Real-time stock tracking
- Low stock alerts
- Auto reorder notifications
- Dead stock detection
- Multi-store support (5 stores)

### Sales Analytics
- Live KPIs dashboard
- Sales trends & forecasting
- Product performance analysis
- Store-wise comparisons
- Custom date range reports

### GST System (Complete)
- GST-compliant invoice generation
- Auto GSTIN lookup & validation
- CGST + SGST (Intra-state)
- IGST (Inter-state)
- GSTR-1 & GSTR-3B reports
- CSV export for filing

### User Management
- Role-based access (Admin, Manager, Analyst)
- Multi-user support
- Store-specific access control
- OTP verification

### Data Management
- CSV/Excel import
- Kaggle dataset integration
- Demo mode with sample data
- Setup wizard for onboarding

### Subscription System
- 4-tier plans (Free, Basic, Pro, Enterprise)
- 14-day free trial
- Feature-based restrictions
