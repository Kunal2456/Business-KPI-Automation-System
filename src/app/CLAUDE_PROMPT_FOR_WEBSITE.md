## 🎨 DESIGN REQUIREMENTS

### **Color Scheme:**
**Primary Colors:**
- Brand Blue: #6366f1 (Indigo-600)
- Brand Purple: #8b5cf6 (Purple-600)
- Accent Orange: #f59e0b (Amber-500)

**Gradients:**
- Hero CTA: `bg-gradient-to-r from-indigo-600 to-purple-600`
- Section backgrounds: `bg-gradient-to-br from-indigo-50 to-purple-50`

**Neutral Colors:**
- Dark text: #1f2937 (Gray-800)
- Light text: #6b7280 (Gray-500)
- Background: #ffffff (White) and #f9fafb (Gray-50)

### **Typography:**
- Headlines (H1): 48-64px, bold, leading-tight
- Subheadlines (H2): 32-40px, semibold
- Body: 16-18px, regular
- Font family: Inter or Poppins or DM Sans (modern, clean)

### **Spacing:**
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8

### **Components:**
- Buttons: Rounded (rounded-lg), shadow on hover
- Cards: White with shadow, hover:scale-105 transition
- Icons: Lucide React, 24px default size
- Images: Rounded corners, subtle shadow

### **Animations (Framer Motion):**
- Scroll animations: Fade in + slide up on viewport enter
- Hero text: Stagger animation (headline → subheadline → CTAs)
- Stat counters: Count up animation when in view
- Feature cards: Hover effect (lift + shadow increase)

### **Responsive:**
- Mobile-first approach
- Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)
- Hero: Stack on mobile, side-by-side on desktop
- Features: 1 column mobile, 2 columns tablet, 3 columns desktop
