## **🌙 Enable Dark Mode**

```
Desktop:
1. Look at the bottom of the sidebar
2. Click the "Dark Mode" button (Moon icon)
3. Enjoy!

Mobile:
1. Tap the Moon icon in the top-right header
2. Dark mode activates
3. Your eyes will thank you
```

---

## **📅 Set Restock Dates**

```
1. Go to "Products & Inventory"
2. Click "Add Product" or Edit an existing one
3. Scroll to "Next Restock Date"
4. Click the calendar and pick a date
5. Save
6. A blue badge will show on the product card
7. You'll get an alert 3 days before!
```

---

## **🏪 Filter by Store**

```
Admin Users:
1. See the "Filter by Store" dropdown in sidebar
2. Select: Store A, Store B, Store C, or All Stores
3. All data updates automatically

Manager Users:
1. Your assigned store is auto-selected
2. Change to "All Stores" to see everything
3. Or select a specific store
```

---

## **🔔 Check Alerts**

```
1. Look for the Bell icon (top-right on mobile, bottom-left on desktop)
2. Red badge shows unread alert count
3. Click to open alerts panel
4. Review alerts:
   🔴 Low Stock - Product needs reordering
   ⚠️ Dead Stock - No sales in 30 days
   📅 Restock Due - Scheduled restock coming up
5. Click "Mark read" to dismiss
```

---

## **🚪 Logout Properly**

```
Desktop:
1. Look at the bottom of the sidebar
2. Click the red "Logout" button
3. You're signed out

Mobile:
1. Tap the menu icon (☰)
2. Scroll to the bottom
3. Tap the red "Logout" button
```

## **🐛 Troubleshooting**

### **Can't Sign In?**
```
✅ Check you're using the correct email
✅ Try demo credentials
✅ Use "Forgot Password" to reset
```

### **Alerts Not Showing?**
```
✅ Add products first
✅ Set stock below reorder level
✅ Wait a few seconds for auto-generation
✅ Click the bell icon to open panel
```

### **Dark Mode Not Saving?**
```
✅ Make sure you're logged in
✅ Toggle the mode again
✅ Refresh the page to verify
```

### **Store Filter Not Working?**
```
✅ Make sure you're Admin or Manager
✅ Check that sales have storeLocation set
✅ Try "All Stores" first
```

```

A: Data is stored locally in your browser. For production, use Supabase integration.
```
